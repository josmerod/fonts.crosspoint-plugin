# Fonts

**289 precompiled font families for your reader, browsable and installable from the web UI.**

## What it does

- Browse a live catalog of `.cpfont` families built with CrossGlyph from the
  WP-Fonts collection, grouped by purpose: *Reading*, *Interface*, *Mono*,
  *Script*, *Display*.
- Preview each family as a page rendered by the reader's own engine.
- Choose exactly which point sizes (6–18 pt) to install; each size is its own
  bitmap file, so you only download what you will use.
- Install straight to the SD card, remove families, and set the active font.
- Filter by name or license; every family links to its license text.

## Where the fonts come from

The catalog lives in [josmerod/cp-fonts](https://github.com/josmerod/cp-fonts)
and is rebuilt automatically, so new families show up without updating this
plugin. You can point the plugin at a different catalog (for example your own
fork) from its settings.

## Things to know

- Families appear under **Settings → Font** right after install — no reboot.
- The reader holds at most **128** installed families.
- Previews load only when you press *Preview*, so a large catalog stays fast.
