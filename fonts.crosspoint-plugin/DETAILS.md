**Precompiled font families for your reader, browsable and installable from the web UI.**

## What it does

- Browse a live catalog of .cpfont families built with CrossGlyph from the WP-Fonts collection, grouped by purpose: Reading, Interface, Mono, Script, Display.
- Preview each family as a page rendered by the reader's own engine.
- Choose exactly which point sizes (6-18 pt) to install; each size is its own bitmap file, so you only download what you will use.
- Install straight to the SD card, remove families, and set the active font.
- Filter by name or license; every family links to its license text.

## How to use it

This plugin works in the web UI; the reader only needs it installed.

1. On the reader, start File Transfer and open its web page in a browser.

2. Open Settings > Fonts.

3. Press Preview to see a family, tick the sizes you want and press Install.

4. On the reader, open Settings > Font and pick the family. It is listed right after the install, with no restart.

## Good to know

- The catalog is rebuilt automatically, so new families appear without a plugin update.
- The reader holds at most 128 installed families; the plugin warns you at the limit.
- Previews load only when you press Preview, so a large catalog stays fast.
- Fonts keep their upstream licenses. This plugin's code is MIT.
